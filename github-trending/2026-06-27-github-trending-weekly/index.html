本周趋势概览

本周 GitHub Trending 是 Agent 基础设施与垂直应用 的双重爆发。榜首 calesthio/OpenMontage 一周狂揽 1.7 万星，把「agentic 视频生产」从概念推进到可工程化的 pipeline；DeusData/codebase-memory-mcp 用 C 语言实现高性能代码知识图谱 MCP server，让 Agent 对大型代码库的理解成本从 Token 消耗角度下降两个数量级。

与此同时，mattpocock/skills 以 14.7 万总星证明 Claude Code skill 生态已进入「工程化最佳实践」阶段；mukul975/Anthropic-Cybersecurity-Skills 则把 Agent 能力引入网络安全领域，映射到 MITRE ATT&CK、NIST CSF 2.0 等六大框架。整体来看，Agent 正在从「能写代码」走向能看视频、能读代码库、能防守安全、能辅助招聘的通用智能层。
